## 1. What this deck is

This is the DESKTOP/BROWSER counterpart to the Bridge4PS mobile tutorial deck. Bridge4PS is a public-safety-focused workplace chat app (channels/rooms, direct messages, teams, workspaces — Slack/Mattermost-like concepts). The deck teaches end users how to use desktop/browser-client features one at a time.

**Layout convention used on nearly every content slide:**
- A title in the form `Desktop: <Feature Name>` (sometimes `Desktop : <Feature Name>` with a space before the colon).
- Numbered step instructions (1, 2, 3…) paired with screenshot images (referenced as `![](PictureN.jpg)` / `GoogleShapeN` placeholders — image content itself was not extracted, only captions/alt text).
- Often a callout "Note:" box with a caveat (who can use the feature, a restriction, a side effect).
- A `### Notes:` section per slide (speaker notes) containing production/revision metadata: "Date Published to Help Desk: [date]", "Note from Daniel: DONE w/ REVISION! ?", "Updated screenshots by Daniel Dakus 09.07.21", and/or "Updated [date]" (most recent editorial pass). These are internal production notes, not user-facing content.
- Slides gated behind a paid tier are marked in-slide with **"Pro Feature"** or **"Pro License Feature"**.

**Structural quirk to know about:** The deck's own Table of Contents (slides 2–6) only maps to slides **7–149**. Slides **150–170** exist in the file but are *not* referenced anywhere in the ToC — see Section 4 ("Things to watch for") for details; several of these are explicitly-marked-obsolete duplicates of earlier slides.

## 3. Per-slide index (slides 7–170)

Legend: **[PRO]** = Pro/Pro License gated feature. **[FLAG]** = see Section 4 for why. "Updated" = most recent date string found in that slide's Notes section (production notes, not in-app dates).

### Channel Actions block

- **7 — Add Users to Channel.** Members panel → Add users → search/select users → Add users. Only a channel owner can add users. Updated 1/13/24.
- **8 — Archive Channel/Room.** Room Info → Edit → Advanced settings → toggle Archived → Save. Only owners can archive; archived rooms stay searchable in Channels Directory; Basic users can access archived rooms only if owned by a Pro user. Updated 1/13/24.
- **9 — Autojoin Channels.** Explains auto-enrollment of new users into channels based on Organization/State/Discipline; one-time setup fee per channel; directs to support@bridge4ps.app. No numbered UI steps (informational slide). Updated 1/13/24.
- **10 — Change Member Roles.** Members panel → filter (Online/All) → hover member → More → set Owner/Leader/Moderator/Remove from room. Defines each role's permissions. Notes flag the feature changed from desktop-only to desktop+mobile. Updated 1/13/24.
- **11 — Channel Search Commands.** Reference list of search operators: `file-desc:`, `from:me`, `from:user.name`, `file-title:`, `has:star`, `is:pinned`/`has:pin`, `has:url`/`has:link`, `has:location`/`has:map`, `before:`/`after:`/`on:` dates, `order:asc`/`order:desc`. Updated 1/13/24.
- **12–13 — Join-Search Public Channels.** Directory icon → Channels tab → search/scroll (public marked with icon) → open channel → Join button. Updated 1/13/24.
- **14 — Clear Browser Cache (Chrome).** Standard Chrome settings walkthrough: Settings → Privacy & Security → Delete browsing data → select time range/Cookies/Cached files → Delete. Updated 1/13/24.
- **15 — Clear Browser Cache (Edge).** Edge Menu → Settings → Privacy → Choose what to clear → check Cached images/Cookies → Clear now. Updated 1/13/24.
- **16 — Create New Channel.** Create (+) icon → optionally add Team/Workspace + Advanced settings → enter details/members → choose channel type → Create. Explains channel types: Broadcast, **Public Channels [PRO]**, Read Only, Private. Updated 1/13/24.
- **17 — Create New Direct Message 1:1.** Directory → Users tab → search user → open profile → click Direct message icon. Updated 1/13/24.
- **18 — Custom Channel-Room Retention Policy [PRO].** Room Info → Edit → toggle "override global retention policy" → edit max message age **using scroll arrows only (typed values won't save)** → Save. Only channel owners can edit. No separate "Updated" date beyond screenshot pass.
- **19 — Edit Room Information. [FLAG]** Room Info icon → Edit → update fields → Save. Only owners can edit. Notes list "Date Published to Help Desk: ???" — unresolved/incomplete metadata.
- **20 — Favorite Rooms.** Click star icon in room header, or hover sidebar room → ellipsis → Favorite/Unfavorite; enable "Favorites" grouping via Display menu. Updated 1/14/24.
- **21–22 — Group by Folders.** Sidebar Sort & Filter menu → ensure "Folders" checked under Group by → hover channel → ellipsis → Add to folder (existing or new folder name) → Create folder. No Notes content on these two slides.
- **23 — Hide Room.** Hover room → 3-dot menu → Hide (or type `/hide #channel-name`). Hidden rooms remain searchable in Channels Directory; applies to Private, Public, DMs, Discussions, Workspaces.
- **24 — Leave Room.** Hover room → 3-dot → Leave → confirm (or `/leave`). Notes: can only leave if invited individually; members added via a team can't leave; last owner must reassign ownership first.
- **25 — Manage Devices.** Avatar → Account section → Manage Devices → view/log out logged-in devices.
- **26 — Manually Manage Data Retention. [FLAG]** Options → set pruning parameters (date/time range, specific users, content types: pinned/discussion messages/threads/attachments) → Prune Messages → Prune. Only channel owners can edit retention. Notes: "Date Published to Help Desk:" left blank.
- **27 — My User Profile.** Avatar → Profile → edit editable fields (status, nickname, bio, unit, rank, secondary org, state) → Save. Name/username/email/org are managed by Mobility4PS and not user-editable.
- **28 — Notifications Preferences.** Options → Notifications Preferences → toggle default on/off → customize desktop/mobile/email alerts → Save.
- **29 — Remove Users from Channel.** Members panel → filter Online/All → hover member → More → Remove from room.
- **30 — Export Messages - Retain Data by Date Range [PRO].** Options → Export messages → set options (date range, HTML/JSON output format) → Export. Delivered via email link / Export View; requires Export Permission on the channel.
- **31 — Retention: Retain Individual Posts [PRO].** Select specific message(s) → Options → Export messages → set options (send via email to a Bridge4PS user and/or additional external emails) → Send. Requires Export Permission.
- **32 — Room Actions – Basic.** Overview of the top-right icon row: Options, Members/User Info, Mentions, Search Messages, Discussions, Threads, Room Info, Video Call.
- **33 — Room Actions – Expanded.** Overview of items nested under Options: Apps (scheduled/reminders), Files, Pinned Messages, Starred Messages, Keyboard Shortcuts, Notifications Preferences, Prune Messages, **Export Messages [PRO]**, Calls.
- **34 — Room Information.** Room Info icon → view description/announcement/topic.
- **35 — Users Directory.** Directory icon → Users tab (default, alphabetical) → click user for profile card. List view can show 25/50/100 per page.
- **36 — User Status.** Avatar → Status dropdown → pick preset (Online/Away/Busy) or Custom Status → enter message → Save.
- **37 — Video Call.** Click Video Call icon → Start Call (opens new browser window); others click "Join" in the thread to enter. Only Chrome and Firefox supported.
- **38 — View Files-Images List. [FLAG]** Open a channel → 3-dot menu → Files → search/filter by type. Notes: "Still need personal Info blurred and arrows to 1, 2, and 3 formatted" (unfinished production task); "Added to table of contents." Last touched by Bill Staney 12/9/2022.
- **39–40 — Threads.** Hover message → Reply in thread (creates thread if none exists) → optional "Also send to channel"; View Threads panel via Threads icon or "View thread" link.
- **41 — Hide User Name.** Accessibility & appearance → Adjustable Layout → toggle "Show usernames" to show/hide the @username next to display names.
- **42 — Hide Avatars.** Preferences → Message section → toggle Display Avatars.
- **43 — Display Condensed.** Sidebar Display icon → Condensed option (smaller icons/spacing).
- **44 — Display Extended.** Sidebar Display icon → Extended option (larger icons, more detail).
- **45 — Collapse Embedded Media.** Preferences → Messages → toggle "Collapse Embedded Media by Default" (media hidden until manually expanded when ON).
- **46 — Auto Load Images.** Preferences → Messages → toggle Auto Load Images (shows "Click to load" prompt when OFF; saves bandwidth).
- **47 — Channel Notification Settings.** 3-dot menu → Notification Preferences → configure alerts, mute @all/@here, mark unread, per-platform (Desktop/Mobile/Email) settings.
- **48 — Room Name.** Room Info icon → Edit → update Room Name field → Save. Owners only.
- **49 — Sort by Activity.** Display icon → Sort by → Activity (rearranges sidebar by recent activity).
- **50 — Public Channel: Show History.** Info icon → Edit → Advanced settings → toggle Hide History → Save. When enabled, only authorized users see history from the directory.
- **51 — Ignore User.** Click user avatar → Ignore option to mute their messages/notifications.
- **52 — Mark Unread.** Hover a room/DM/Discussion → 3-dot → Mark Unread → moves it to the Unread list.
- **53 — Keyboard Shortcuts.** 3-dot menu (top right) → Keyboard Shortcuts.
- **54 — Group By Type.** Display icon → toggle "Types" ON to group rooms by category (Workspaces/Discussions/Public/Private) or OFF for one merged Conversations list.
- **55–56 — Don't ask me again list.** Example flow: Hide a channel → tick "Don't ask me again" in the confirmation popup; view/manage saved suppressions later via Preferences → Global → Don't ask me again list.
- **57 — Alerts on Desktop Browser (ToC calls this "Desktop Alert").** Avatar → Preferences → Notifications section → configure desktop/push/email alert behavior (all messages vs. mentions only).
- **58 — Preview Public Channel: Show History.** Directory → Channels tab → select public channel to preview message history → Join to become a member. Preview unavailable if owner enabled "Hide History."
- **59 — Set React When Read Only.** Open owned channel → Edit → Advanced Settings → Security and Permissions → turn ON Read-only → enable "Allow reacting" → Save. Only owners/moderators can post in Read-only mode.
- **60 — User Settings.** Overview of the avatar dropdown menu: Profile, Preferences, Accessibility & Appearance, Feature Preview, Logout, plus quick status switching.
- **61 — Bridge4PS Channel Types.** Reference slide (no steps) explaining Public Channels, Private Groups, Discussions, and Direct Messages with use cases (e.g., Discussions used for "Incident Within an Incident"/IWI).

### Message Actions block

- **62 — Add Reminder.** Three ways: `+` icon → Add Reminder; hover message → "Remind me about this"; or `/remind` command. Reminders can target self/other users/whole channel, be one-time or recurring, use local time zone.
- **63 — Audio Messages.** Click mic icon in message box → record → checkmark to stop → enter filename/description → Send. Playable/downloadable across desktop/iOS/Android with adjustable playback speed.
- **64 — Copy Content.** Hover message/file → Message Actions → Copy. Only the raw message text is copied (not sender, timestamp, or channel); files/images must be downloaded separately.
- **65 — Delete File.** 3-dot menu on the file's message → Delete.
- **66 — Delete Individual Posts.** Hover message → 3-dot → Delete → confirm ("Yes, delete").
- **67 — Discussions.** Sub-rooms within a channel that any member can start; visible to all room members (Desktop) but only Discussion members get notifications; leave via 3-dot → Leave. Used by some agencies for "IWI" (Incident Within an Incident).
- **68 — Discussions - Start a Discussion.** 3-dot on a message → Start a Discussion → name/topic/add members (original author auto-added) → optionally add whole Teams.
- **69 — Download Files.** Method 1: cloud-download icon on the post. Method 2: Room Actions → Files list → ellipsis on file → Download. Updated 1/13/24.
- **70 — Edit Message.** Hover message → Message Actions → Edit → change text → Send. Edited messages show a pencil icon; no notification is sent to others.
- **71 — Copy Link.** Hover message/file → Message Actions → Copy Link → paste anywhere in B4PS; opens in-app with original sender/timestamp; requires channel membership + login.
- **72 — Read Receipts.** Hover message → 3-dot → Read receipts → popup shows username/date/time each member viewed it.
- **73 — Leave Direct Chat Message-Block User.** DM list → open chat → click user's profile picture → Block icon. Blocking sets the DM Read-Only for both users.
- **74 — Mentions.** `@here` notifies active users, `@all` notifies everyone. Color coding: orange = broadcast, red = referring to self, gray = other users.
- **75 — Message Actions.** Overview slide listing all hover-menu actions: Pin, Star, Copy Link, Copy, Info/Read Receipts, Edit, Delete, Remind Me.
- **76–77 — Message Formatting.** Bold/Italics/Strikethrough/Code snippet formatting via toolbar buttons or manual wrapping symbols; also covers `/giphy`, `/topic`, `/shrug`, `/hide`+`/unhide`, `/archive`+`/unarchive` slash commands (overlaps with the dedicated Slash Commands slides).
- **78 — Message Actions from Message Box.** `+` icon next to the message box → Start a Discussion, Share Location, Schedule Message, Add Reminder, record video/audio.
- **79 — Reactions.** Add new reaction / add to an existing one (click it) / remove your reaction (click again) / view who reacted (hover the emoji).
- **80 — Reply in Direct Chat Message.** 3-dot menu on a channel message → Reply in direct message → opens a DM quoting the original for context.
- **81 — Share Files.** Drag-and-drop onto the app, or `+` icon → Computer to browse and upload; enter filename (editable) + optional description → Send.
- **82 — Slash Commands (overview).** Begin a message with `/` to see the command list; some commands trigger a Bridget.Bot response visible only to the sender.
- **83 — Slash Command/Poll.** `/poll` → fill form (question + answers; Multiple Choice/Open Vote/Confidential/Mixed visibility) → posts as clickable-button poll for all members.
- **84 — Slash Commands/Channels.** `/create #channelname` (only PRO License users can create public channels), `/topic`, `/hide`+`/unhide`, `/archive`+`/unarchive`.
- **85 — Slash Commands/Manage Members (1).** `/invite`, `/invite-all-to #channel`, `/invite-all-from #channel`, `/join #channel`.
- **86 — Slash Commands/Manage Members (2).** `/leave`, `/part @user`, `/kick @user`.
- **87 — Slash Commands/Messages.** `/shrug`, `/giphy`, `/msg @user <message>` (private message).
- **88 — Slash Commands/Other Actions.** `/help`, `/mute @user`, `/unmute @user`, `/status <message>`.
- **89 — Slash Command/Schedule Posts.** `/sendlater` or `+` → Schedule Message; 3 methods: duration from now, time later today, time on a specific future date.
- **90 — Slash Command/Recurring Posts.** Same `/sendlater` flow, but with a recurring-frequency option: Do not repeat / Every Hour / Daily / Weekly / Monthly.
- **91 — Timestamp.** Timestamp shown next to sender name; hovering shows full date/time. 12-hour is default; switch to 24-hour via Accessibility & appearance → Adjustable layout → Time Format. Updated 1/13/23 (date as written in the deck).
- **92 — Search Files-filter by type.** 3-dot menu → Files → filter dropdown by type (images/video/audio/text). Note: paperclip icon is on the sidebar directly in DMs/Discussions but nested in the options menu for Channels.
