## 1. What this deck is

This is the **Mobile App** edition of the Bridge4PS feature-tutorial deck (Bridge4PS is a
Slack/Mattermost-style workplace chat app built around channels/rooms, teams, and workspaces).
Slide 1 is titled "Mobile App / Features Tutorials" and stamped **Last Modified 06/28/2026**.

- **Total slides: 171**
- **Slide 1**: title/cover slide.
- **Slides 2–7**: the deck's own **Table of Contents**, split across 6 slides by category
  (Channel Actions, Message Actions, Teams Actions), each listing feature names next to the
  slide number(s) where they live.
- **Slides 8–171**: the actual content/tutorial slides (164 slides).

**Layout convention** used by nearly every content slide:
- A bold title in the form `Mobile App: <Feature Name>` (occasionally `Mobile App : <Feature Name>`).
- A numbered list of step instructions (numbers 1, 2, 3… placed next to matching screenshot images).
- One or more screenshot images (rendered in the raw extraction as generic `![](PictureN.jpg)` /
  `![](GoogleShapeNpNN.jpg)` placeholders — the extraction captures alt text only, not the images).
- Often an italic/plain "Note:" callout with a caveat, permission rule, or clarification.
- A `### Notes:` section at the bottom of the slide block, which corresponds to the PowerPoint
  **speaker notes** — used inconsistently across the deck for: revision history ("Updated by
  Daniel Dakus 04/27/21"), production reminders ("Hide bridge2ps on top", "Font size and font"),
  multi-slide-set markers ("Slide 1 of 2"), or genuine open issues ("DID NOT EDIT THIS SLIDE").
- A trailing page number repeated as plain text (matches the slide number).

Some features span **multiple physical slides** (e.g., a 2-slide or 3-slide set for one topic);
the ToC lists these as a slide range like `66-67`.
