## A. Candidate Current Editorial Style — plain language

The style I found the strongest, most consistent evidence for looks like this: a row of red
numbered circles across the top, short bold-keyword instructions next to each number, and one or
two big, real screenshots below showing the actual app in context. Highlighting is a plain red
rectangle drawn around just the one thing to click — never a web of arrows across the screen.
When a slide needs to show a before/after state, a single gray arrow connects two side-by-side
screenshots. This pattern shows up consistently across both the deck's earlier and later
sections — it is not confined to any one part of the deck.

## D. Key visual grammar rules (high confidence only)

- Red circle number = a step in sequence.
- Red rectangle outline = "click this exact thing."
- Gray arrow between two screenshots = "this state becomes that state."
- Bold "Note:" paragraph = a caveat, permission requirement, or scope note.
- "Pro License Feature" label = this is a paid-tier capability.
